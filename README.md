
Скрипт на Python для вычисления центральности по собственному вектору (eigenvector centrality) на графе из 15 узлов с использованием библиотеки NetworkX. Структура графа подобрана так, чтобы итоговые значения центральности образовывали распределение в форме горки — с пиком в центральном узле и плавным понижением к краям.


Дано требование: построить граф из 15 узлов, для которого центральность по собственному вектору, упорядоченная по номерам узлов от 1 до 15, образует горку — растёт к середине списка и убывает к его краям. Структуру графа необходимо подобрать вручную.


В качестве графа выбран простой путь P15 — цепочка узлов, последовательно соединённых рёбрами (1, 2), (2, 3), ..., (14, 15). Такая топология естественным образом приводит к нужному распределению: узлы 1 и 15 имеют по одному соседу и получают минимальные значения, тогда как узел 8, расположенный в середине цепочки, окружён хорошо связанными соседями и получает максимальное значение. Поскольку eigenvector centrality учитывает важность соседей, а не только их количество, значения симметрично убывают по мере удаления от центра.

Технологии:

Python 3.9, NetworkX 3.2.1.
 
Запуск:

Установить зависимости:

    pip install networkx

Запустить скрипт из корневой папки проекта:

    python3 main.py

Результат работы:

В консоль выводится 15 строк формата `Узел N: значение`, где значение указано с точностью до четырёх знаков после запятой. Распределение симметрично относительно узла 8 и имеет форму горки.
